## 2. ขอบเขตที่ตรวจ

- หลังบ้าน: งานเงินเดือนประจำเดือน (ปิดเวลา → คำนวณ → อนุมัติ → ไฟล์ธนาคาร → สลิป → สปส.1-10 → ภ.ง.ด.1 → ปิดงวด), แท็บ “รอเข้างวด” ใหม่, การอนุมัติ 14 ประเภทเอกสาร, ตั้งค่ากฎการคำนวณ / PDPA / รหัสผ่าน, Back Log, รายงานราชการ, ประวัติพนักงาน, การเคลื่อนไหว, ทดลองงาน, นำเข้า CSV, โควต้าการลา, เอกสารพิมพ์
- แอปพนักงาน `/m`: เข้าสู่ระบบครั้งแรก, ลงเวลา GPS / ออฟไลน์, ยื่นลา / สวัสดิการ / ร้องเรียน, สลิป, ข้อมูลของฉัน, แจ้งเตือน, ออกจากระบบ
- ความปลอดภัย: การเข้าถึงของพนักงานที่พ้นสภาพ, ความลับของใบร้องเรียน, มือถือใช้ร่วมกัน, ล็อกบัญชีเมื่อใส่รหัสผิด

## 6. ข้อแนะนำก่อนส่งมอบ

1. ทำ P1 สองรายการแรก (final settlement + สปส.1-03/6-09) ก่อน go-live ลูกค้าที่มีพนักงานเข้า-ออกเป็นประจำ หรือแจ้งลูกค้าเป็นลายลักษณ์อักษรว่าเวอร์ชันนี้ยังทำนอกระบบ
2. คำนวณเงินเดือนคู่ขนานกับระบบเดิม 1 งวดตาม checklist ย้ายข้อมูล และตรวจไฟล์ธนาคาร/สปส. กับธนาคารและ e-Service ก่อนใช้จริง (ข้อจำกัดใน docs/FEATURES.md)
3. ตั้ง cron backup + คัดลอกออกนอกเครื่อง และซ้อมกู้คืน 1 ครั้งบน staging ก่อนส่งมอบ
4. ติดตั้งแล้วเปิด CSP แบบรายงานอย่างเดียว 2 สัปดาห์ แล้วตั้ง `CSP_ENFORCE=1`
5. อบรม HR เรื่องขั้นตอนพ้นสภาพ: ต้องใส่ “วันทำงานวันสุดท้าย” เสมอ (บัญชีถูกปิดอัตโนมัติวันถัดไป) และวิธีจ่ายเงินงวดสุดท้ายด้วย “งวดพิเศษ” จนกว่าจะมีหน้า final settlement
