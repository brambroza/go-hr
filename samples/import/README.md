# ไฟล์ทดสอบการนำเข้า (พนักงาน 10 คน)

ข้อมูลในโฟลเดอร์นี้เป็นข้อมูลสมมติ ใช้ทดลองนำเข้าข้อมูลตอนเริ่มใช้ระบบ ชื่อ เบอร์โทร อีเมล และเลขบัญชีเป็นของปลอมทั้งหมด เลขประจำตัวประชาชนขึ้นต้นด้วย 19999 และผ่านการตรวจหลักสุดท้าย แต่ไม่ใช่เลขของคนจริง

นำเข้าตามลำดับนี้:

0. `0-org-structure.csv` ที่ **ตั้งค่า › ย้ายข้อมูลเข้าระบบ › นำเข้าโครงสร้างองค์กร** มีสาขา 2 แห่ง หน่วยงาน 10 หน่วย และตำแหน่ง 12 ตำแหน่ง ต้องนำเข้าก่อน เพราะไฟล์พนักงานอ้างถึงรหัสเหล่านี้
   - ถ้านำเข้าที่ระบบเดโม่ซึ่งมีรหัสเหล่านี้อยู่แล้ว ระบบจะอัปเดตชื่อตามไฟล์ เช่น หน่วยงาน C จะเปลี่ยนชื่อเป็น "บริษัท ตัวอย่าง จำกัด"
1. `1-employees.csv` ที่ **พนักงาน › นำเข้าพนักงาน** มีพนักงาน 10 คน รหัส T001 ถึง T010
   - T001 เป็นหัวหน้าไลน์ผลิต และเป็นหัวหน้างานของ T002 ถึง T007
   - มีทั้งรายเดือนและรายวัน สถานะประจำ ทดลองงาน และสัญญาจ้าง และอยู่ 2 สาขา (HQ, RY)
2. `2-opening-ytd.csv` ที่ **ตั้งค่า › ย้ายข้อมูลเข้าระบบ › นำเข้ายอดสะสม** เป็นยอดเงินได้ ภาษี ประกันสังคม และกองทุน ม.ค. ถึง ก.ย. 2569
   - มี 9 คน T005 ไม่มีในไฟล์ เพราะเริ่มงาน 1 ก.ย. 2569 ซึ่งเป็นเดือนที่เริ่มใช้ระบบ
   - ยอดภาษีเป็นตัวเลขประมาณ ไว้ทดสอบเท่านั้น
3. `3-leave-balances.csv` ที่ **ตั้งค่า › ย้ายข้อมูลเข้าระบบ › นำเข้าวันลา** เป็นสิทธิ์ลาป่วย ลากิจ และลาพักร้อนปี 2569 พร้อมวันที่ใช้ไปแล้ว รวม 27 แถว ประเภทลา SICK, PERSONAL และ VACATION ระบบสร้างไว้ให้ตั้งแต่ติดตั้ง

ถ้าเห็นข้อความ "ไม่พบสาขารหัส HQ" ตอนนำเข้าพนักงาน แปลว่ายังไม่ได้นำเข้าไฟล์ 0

ไฟล์บันทึกเป็น CSV UTF-8 เปิดและแก้ใน Excel ได้ ถ้านำเข้าซ้ำ ระบบจะอัปเดตข้อมูลของรหัสเดิม ไม่สร้างพนักงานซ้ำ

ถ้าอยากล้างข้อมูลทดสอบออกจากฐานข้อมูลเดโม่:

```sql
update employees set supervisor_id = null where code like 'T0%';
delete from employees where code like 'T0%';
```

ข้อมูลจากไฟล์ 0 ลบได้ที่หน้า องค์กร › สาขา / โครงสร้างองค์กร / ตำแหน่งงาน (ลบหลังลบพนักงานที่อ้างถึงแล้ว)
